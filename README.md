#QSimplePOS
A QSimplePOS is a simple restaurant POS system made with C++ and Qt Framework
##Features
- Core POS Capabilities: Can handle daily POS routines easily
- Item management: Easily add and remove items
- Manager interface: Includes a simple manager menu for administrative tools
- JSON: Moduler JSON file intergration
- Unit tests: Integrated with unit tests through QSimplePOSTEST project
